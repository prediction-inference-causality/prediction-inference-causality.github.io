This is a guide for translating .Rnw files to .qmd files. This is a **format translation task**, not a rewriting one.

# CRITICAL 
1. do not change anything within a math environment AT ALL 
2. do not change my content or phrasing---not even to something mathematically equivalent. 
3. do not change the number or the title of any slides
4. do not change the Rnw file at all. The one exception is the addition of set.seed in the event of nondeterminism as described below in the validation section.

# Approach
1. translate sequences of images that use \only<> within a \begin{figure} ... \end{figure} environment into TABS in the qmd file
2. translate bulleted (itemize) and numbered (enumerate) lists into their markdown equivalents. note that markdown lists must be separated from other content by one line of space above and below.

# Validation
- Check that the qmd you give me compiles (run 'quarto render')
 - check that when you compile the new qmd file (run 'quarto render'), the svgs generated are the same as the ones generated when you compile the Rnw one (run 'latexmk').  
-  if they don't match, first check whether the ones generated by the Rnw file are deterministic. If not, add set.seed(1) to a code block at the top the Rnw file, check that that fixes the nondeterminism issue, and then try again to match it with the qmd
You can run latexmk (again) to compile the Rnw file to generate the svgs.  If you identify nondeterminism in the Rnw file, you should tell me and ask whether adding set.see(1) is ok before doing it.
