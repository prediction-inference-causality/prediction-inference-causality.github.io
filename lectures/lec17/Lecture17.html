Least Squares Regression with Linear Models

\[ \hat \mu = \argmin_{m \in \model} \frac{1}{n}\sum_{i=1}^n \qty{ m(\textbf{X}_i) - Y_i}^2 \qqtext{ for } \model = \qty{ m(x) = \sum_k b_k \phi_k(x) : b \in \R^{K+1} } \]

  • In this class, we focus on fitting linear models via least squares.
  • You can think of linear models, generally speaking, as the set of all linear combinations of a set of features.
  • We’ve been doing this for a while, but it was only last class that we talked about it in general.
  • Let’s go through a few familiar examples.

The Saturated Model

  • This is the model we’ve worked with most.
  • In this model, we have a feature for every level of \(x\).
  • That feature is just a binary indicator that \(X_i\) takes on that value.
  • The least squares curve in this model is just the subsample mean of \(Y_i\) at each level of \(x\)

\[ \small{ \hat \mu(x) = \frac{1}{N_x}\sum_{i:X_i=x} Y_i \qqtext{ for } \model = \qty{ m(x) = \sum_j b_k 1_{x_k}(x) : b_k \in \R } } \]

Lines and Polynomials

  • We’ve also worked with the set of lines.
  • But with many-valued \(x\), we started having to worry about misspecification.
  • To reduce misspecification, people often use higher-order polynomials instead.

\[\small{ \begin{aligned} \model &= \qty{ m(x) = b_0 + b_1 x : b \in \R^2 } && \textcolor{blue}{\text{lines}} \\ \model &= \qty{ m(x) = b_0 + b_1 x + b_2 x^2: b \in \R^3 } && \textcolor{red}{\text{quadratic polynomials}} \\ \model &= \qty{ m(x) = b_0 + b_1 x + b_2 x^2 + b_3 x^3 : b \in \R^4 } && \textcolor{magenta}{\text{cubic polynomials}} \end{aligned} } \]

Bivariate Line-Based Models Models

  • In the last two classes, we’ve talked about two bivariate models.
  • In additive models, we get parallel lines for each level of \(z\).
  • In interacted models, we get totally different lines for each level of \(z\).
  • In this case, they look very similar.

\[\small{ \begin{aligned} \model &= \qty{ m(x,z) = b_0 + b_1x + b_2 z : b \in \R^3 } &&\text{additive bivariate lines} \\ \model &= \qty{ m(x,z) = b_0 + b_1x + b_2 z + b_3 x z: b \in \R^4 } &&\text{interacted bivariate lines} \\ \end{aligned} } \]

Bivariate Polynomial Models

  • We can also do this with polynomials. Here we’re doing cubics.
  • In additive models, we get parallel polynomials for each level of \(z\). They differ by a constant.
  • In interacted models, we get totally different polynomials for each level of \(z\).
  • These are different. With different cubics, we can go through the subsample means. But with parallel ones, we can’t.

\[\small{ \begin{aligned} \model &= \qty{ m(x,z) = b_0 + b_1x + b_2 x^2 + b_3 x^3 + b_4 z : b \in \R^5 } &&\text{additive bivariate cubics} \\ \model &= \qty{ m(x,z) = b_0 + b_1x + b_2 x^2 + b_3 x^3 + b_4 z + b_5 x^2z + b_6 x^2 z + b_7 x^3 z: b \in \R^8 } &&\text{interacted bivariate cubics} \\ \end{aligned} } \]

Saturated Models Can Be Too Big

  • So far, we’ve had relatively few levels of the covariates.
    • This meant we could usually get away with using saturated models.
    • And it seemed like a good idea because the consequences of misspeccification are pretty bad.
  • But when we use more covariates—or covariates with more levels—we get noisy estimates.
  • Here we’re plotting income (y) against education level (x) and year (z) for surveyed Manhattan residents.

Saturated Models Can Be Too Big

  • There are 10 levels of education and 4 years, so we have 40 levels of the covariates—40 subsamples.
    • Some of these are very small. As a result, who happens to get surveyed has a big effect on the subsample mean.
    • And we see that they jump around a lot. That’s probably not what’s going on in the population.
  • It’s even possible that we get ‘subsamples’ of zero people.
    • i.e., possible levels of the covariates that we don’t get in the sample.
  • To get around this, we have to use models with fewer features.

Smaller Models

  • Here’s an interacted model with 8th-order polynomials.
    • This has \(4 \times 9 = 36\) features.
    • That’s almost as big as the saturated model.
  • And we see it’s similarly messy.

Smaller Models

  • Here’s an interacted model with 3rd-order polynomials.
    • This has \(4 \times 4 = 16\) features.
    • That’s much smaller. And it’s less noisy.

Smaller Models

  • Here’s an additive model with 8th-order polynomials.
    • This has \(4 + 8 = 12\) features.
    • That’s even smaller. And it’s not too noisy either.
  • Note that it looks ok at observed levels of the covariate but does weird stuff in between.
  • High-order polynomials do that. Be careful if you want predictions at unobserved levels of the covariate.

Smaller Models

  • An alternative to polynomials is piecewise-constant models.
  • These are sets of curves that are constant between specified levels of the covariate—where they jump.
  • We have seen this already.
    • We spoke for a while about using 4-year degree status instead of education.
    • This is a piecewise-constant model with a jump at \(x=16\).

Summary

  • When you have many covariates or many-valued covariates, you may not want a saturated model.
  • There are lots of models you can choose from.
  • We’ll talk about how to choose in a few weeks.
  • But before we get there, we’ll talk about the consequences of our choice.

Least Squares with Linear Models

Orthogonality of Residuals to Features

  • The residuals \(\hat\varepsilon_i = Y_i - \hat\mu(X_i)\) are orthogonal to the every feature \(\phi_k(X_i)\).

  • That is, the dot product between the vector of residuals and the vector of feature observations is zero. \[ \small{ \begin{aligned} \hat\varepsilon^T \phi_k(X) = \begin{pmatrix} \hat\varepsilon_1 & \hat\varepsilon_2 & \ldots & \hat\varepsilon_n \end{pmatrix} \begin{pmatrix} \phi_k(X_1) \\ \phi_k(X_2) \\ \vdots \\ \phi_k(X_n) \end{pmatrix} = \sum_{i=1}^n \hat\varepsilon_i \phi_k(X_i) = 0 \qfor k=0,1,\ldots,K \end{aligned} } \]

  • This is what that looks like in 2D, i.e., when we have two observations.

    • We plot the feature and residual for one observation on the \(x\)-axis and the other on the \(y\)-axis.
    • We’ve used only one feature in each regression.
    • If we used more, our plot would be less interesting. Why?

Orthogonality of Residuals to Curves

  • This means they’re orthogonal to every curve \(m(x)\) in the model. \[ \small{ \begin{aligned} \hat\varepsilon^T \phi_k(X) = \begin{pmatrix} \hat\varepsilon_1 & \hat\varepsilon_2 & \ldots & \hat\varepsilon_n \end{pmatrix} \begin{pmatrix} m(X_1) \\ m(X_2) \\ \vdots \\ m(X_n) \end{pmatrix} = \sum_{i=1}^n \hat\varepsilon_i m(X_i) = 0 \qfor m \in \model. \end{aligned} } \]

  • That’s because curves in the models are linear combinations of features.

  • And linear combinations of zeros are zero.

\[ \small{ \begin{aligned} \sum_{i=1}^n \hat\varepsilon_i m(X_i) &= \sum_{i=1}^n \hat\varepsilon_i \qty{ \sum_k b_k \phi_k(X_i) } && \text{ for some $b_0,b_1,\ldots$ for any $m \in \model$ } \\ &= \sum_{i=1}^n \sum_k b_k \hat\varepsilon_i \phi_k(X_i) && \text{ distributing } \\ &= \sum_{k} b_k \sum_{i=1}^n \hat\varepsilon_i \phi_k(X_i) && \text{ re-ordering sums and pulling out constants } \\ &= \sum_{k} b_k \times 0 = 0 && \text{ because residuals are orthogonal to features}. \end{aligned} } \]

Uncorrelatedness of Residuals

  • If the constant \(1\) is in the model, this means they’re uncorrelated with every curve in the model. Why?

  • Because the covariance of the residuals and \(m\) is the dot product of the residuals and another function \(m-\bar m\). \[ \sum_{i=1}^n \qty{m(X_i) - \bar m} \hat\varepsilon_i = \sum_{i=1}^n \tilde m(X_i) \hat\varepsilon_i \qfor \tilde m(x) = m(x)-\bar m. \]

  • And that function is in the model too, as it’s a linear combination of two curves in the model. \[ \small{ m \in \model \qqtext{ and } 1 \in \model \implies m - \bar m \times 1 \in \model \qqtext{ for the `coefficient' } \bar m = \frac{1}{n}\sum_{i=1}^n m(X_i) } \]

Orthogonality Proof

\[ \small{ \qqtext{Let's prove that } \sum_{i=1}^n \hat\varepsilon_i \phi_k(X_i) = 0 \qfor k=0,1,\ldots,K } \]

\[ \begin{aligned} 0 &= \frac{\partial}{\partial b_k}\mid_{b=\hat\beta} \frac{1}{n}\sum_{i=1}^n \qty{ \sum_{j=0}^K b_j \phi_j(X_i) - Y_i}^2 \\ &= \frac{1}{n}\sum_{i=1}^n 2 \qty{ \sum_{k=0}^K \beta_k \phi_k(X_i) - Y_i } \phi_k(X_i) \\ &= \frac{1}{n}\sum_{i=1}^n 2 \qty{ \hat\mu(X_i) - Y_i } \phi_k(X_i) \\ &= \frac{1}{n}\sum_{i=1}^n 2 \qty{ -\hat\varepsilon_i } \phi_k(X_i) \\ &= -\frac{2}{n}\sum_{i=1}^n \hat\varepsilon_i \phi_k(X_i) \end{aligned} \]

  • Versions of this proof come up a lot. It’s an important one to remember.
  • You can work out almost everything there is to know about least squares from it.

Limits

  • Suppose our observations \((X_1,Y_1) \ldots (X_n,Y_n)\) are sampled with replacement from a population \((x_1, y_1) \ldots (x_m,y_m)\).

  • The law of large numbers tells you that, for any curve \(m\), …

    • Mean squared error in the sample approximates its expected value.
    • And that expected value is mean squared error in the population. \[ \frac{1}{n}\sum_{i=1}^n \qty{ m(X_i) - Y_i }^2 \approx \E\qty{ m(X_i) - Y_i}^2 = \frac{1}{m}\sum_{j=1}^m \qty{ m(x_j) - y_j }^2 \]

  • That suggests that if we minimize these two errors over curves in the same model, we should get similar curves.

  • i.e., our least squares estimator approximates the population least squares curve. \[ \hat\mu = \argmin_{m \in \model} \frac{1}{n}\sum_{i=1}^n \qty{ m(X_i) - Y_i }^2 \qqtext{approximates} \tilde\mu = \argmin_{m \in \model} \frac{1}{m}\sum_{j=1}^m \qty{ m(x_j) - y_j }^2. \]

  • This is — roughly speaking — what actually happens.

  • For the models we’ll use in this class, this approximation is very good.

  • There are some subtleties here that come up when you use very large models.

  • You can learn about them, e.g. in my Machine Learning Theory class.

Population Least Squares

  • We can say all this residual orthogonality stuff for least squares in the whole population.
  • All curves in the model are orthogonal to the population residuals.

\[ \begin{aligned} \tilde \mu &= \argmin_{m \in \model} \frac{1}{m}\sum_{j=1}^m \qty{ m(x_j) - y_j }^2 && \text{the population least squares curve} \\ \tilde \varepsilon_j &= y_j - \tilde \mu(x_j) && \text{the population residuals} \\ 0 &= \sum_{j=1}^m \tilde \varepsilon_j m(x_j) && \text{ for all $m \in \model$ } \end{aligned} \]

  • We can see something interesting when we write this in terms of random variables and expectations.
  • The errors our population least squares estimator makes—as an estimator of the conditional mean \(\mu(x)\)—are orthogonal to all curves in the model.

\[ \small{ \begin{aligned} \tilde \mu = \argmin_{m \in \model} \E[ \qty{ m(X_i) - Y_i }^2 ] \qqtext{ satisfies } 0 &= \E\qty[ \qty{Y_i - \tilde \mu(X_i)} m(X_i) ] && \text{for all} \quad m \in \model \\ &= \E\qty[ \E\qty[ \qty{Y_i - \tilde \mu(X_i)} m(X_i) \mid X_i ]] &&\text{via iterated expectations} \\ &= \E\qty[ \qty{\E\qty[Y_i \mid X_i] - \tilde\mu(X_i)} m(X_i) ] &&\text{via linearity of cond. expectations} \\ &= \E\qty[ \qty{\mu(X_i) - \tilde\mu(X_i)} m(X_i) ] &&\text{by definition of $\mu$} \end{aligned} } \]

  • This suggests that the population least squares estimator doesn’t depend on variation \(Y_i-\mu(X_i)\) around the subsample means.
  • It’s the curve in the model that best fits the subpopulation means. We can see that more directly, too.

Proof: Population Least Squares as Noiseless

\[ \text{Our claim: } \tilde\mu = \underset{\text{\color{gray}'noisy' population least squares}}{\argmin_{m \in \model} \E[ \qty{ m(X_i) - Y_i }^2 ]} = \underset{\text{\color{gray}'noiseless' population least squares}}{\argmin_{m \in \model} \E[ \qty{ m(X_i) - \mu(X_i) }^2]} \]

\[ \small{ \begin{aligned} &\E\qty[ \qty( m(X_i) - Y_i )^2 ] \\ &= \E\qty[ \qty( \qty{m(X_i) - \mu(X_i)} + \qty{\mu(X_i) - Y_i} )^2 ] && \text{ adding and subtracting }\\ &= \E\qty[ \qty{m(X_i) - \mu(X_i)}^2 + 2\qty{m(X_i) - \mu(X_i)} \qty{\mu(X_i) - Y_i} + \qty{\mu(X_i) - Y_i}^2 ] && \text{ via FOIL } \\ &= \E \qty{m(X_i) - \mu(X_i)}^2 + 2\textcolor{blue}{\E\qty{m(X_i) - \mu(X_i)} \qty{\mu(X_i) - Y_i}} + \textcolor{red}{\E\qty{\mu(X_i) - Y_i}^2} && \text{ via linearity of expectations } \end{aligned} } \]

  • Here the third term doesn’t depend on \(m\), so it doesn’t change the minimizer.
  • And the second term is zero. \[ \small{ \begin{aligned} &\textcolor{blue}{\E \qty{m(X_i) - \mu(X_i)} \qty{\mu(X_i) - Y_i}} \\ &= \E\qty[ \E\qty[ \qty{m(X_i) - \mu(X_i)} \qty{\mu(X_i) - Y_i} \mid X_i]] && \text{ via iterated expectations} \\ &= \E\qty[ \qty{m(X_i) - \mu(X_i)} \qty{\mu(X_i) - \E[Y_i \mid X_i]}] && \text{ via linearity } \\ &= \E \qty{m(X_i) - \mu(X_i)} \E\qty{\mu(X_i) - \mu(X_i)} = 0 &&. \end{aligned} } \]

Bias

  • As sample size increases, the least squares line gets increasingly close to the population least squares line.
  • But the population least squares line is not close to all the subpopulation means.
  • As a result, no matter what sample size we use, we’ll get bias.
  • It’s useful to think of our error at having two pieces.
    • estimation error. This is random. It depends on the sample.
    • modeling error. This isn’t. It depends only on the model and the population.
  • Estimation error goes away in large samples. Modeling error doesn’t.

\[ \hat\mu(x) - \mu(x) = \underset{\text{estimation error}}{\qty{ \hat\mu(x) - \tilde\mu(x) }} + \underset{\text{modeling error}}{\qty{ \tilde\mu(x) - \mu(x) }} \]

  • All this passes through to summaries. What are the two parts of the average-over-years summary?

Inference

\[ \hat\mu(x) - \mu(x) = \underset{\text{estimation error}}{\qty{ \hat\mu(x) - \tilde\mu(x) }} + \underset{\text{modeling error}}{\qty{ \tilde\mu(x) - \mu(x) }} \]

  • The estimation error has mean zero and is approximately normal with variance proportional to \(1/\sqrt{n}\).
  • And the modeling error does not depend on the sample at all—it’s constant. It’s the bias.
  • This is exactly the scenario we looked at on the last question on Midterm 2.
  • That, fundamentally, is what happens when you do least squares with linear models.
