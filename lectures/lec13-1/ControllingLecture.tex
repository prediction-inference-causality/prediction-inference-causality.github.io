\subsection*{Controling}
\bi
\item partial (and extra partial) regression plot (Frisch-Waugh-Lovell Theorem)
\item works for any number of variables
\item what this implies for x and z uncorrelated.


\item 
\begin{eqnarray*}
\hat{B}_{x} & = & \frac{R_{xy} - R_{xz}R_{yz}}{1-R_{xz}^2}(\frac{s_y}{s_x})
\end{eqnarray*}

\noindent If $R_{xz} = 0$ then 
$$\hat{B}_{x} = \frac{R_{xy} - 0\cdot R_{yz}}{1-0^2}(\frac{s_y}{s_x}) = 
R_{xy}(\frac{s_y}{s_x})$$
\noindent This is the simple linear regression estimator for the slope of a regression of $y$ on $x$ only.    

\ei
